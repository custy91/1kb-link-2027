# Link Hub Pro

create a webapp for a link shortner + analytics + dynamic qr gen + qr scanner + emoji short links + pdf links . take the ui style from https://officecommun.com/search


## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
